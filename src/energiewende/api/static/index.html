Energie-Fragen-Agent

Fragen Sie nach Strompreisen, Stromerzeugung, Wetter oder nach Bundestagsdrucksachen zur Energiepolitik. Der Agent sucht sich die passenden Daten selbst und nennt seine Quellen. Jede Frage wird einzeln beantwortet.

Daten: Bundesnetzagentur | SMARD.de (CC BY 4.0) · Open-Meteo.com, Daten des DWD (CC BY 4.0) · Deutscher Bundestag/Bundesrat – DIP. Antworten werden von einem KI-Modell erstellt und können Fehler enthalten.
